🕯️ Midnight Alibi

A party deduction game narrated by an AI host. Pass one phone around the table.

The AI Host

Create a key at enter.pollinations.ai/keys. It is stored only on this device and sent only to gen.pollinations.ai. Without a key the game still runs with built-in mystery scenarios (no live narration).

Players (4–12)

House rules

How to play
One player sets up the phone. The AI host invents a fresh mystery and deals a secret role to every player. Each round the host narrates a new twist, then the group discusses under a timer, then everyone votes pass-and-play. Catch the culprit before the rounds run out. Roles, votes and the winner are decided by the game engine: the AI only writes the story, so it can never leak who did it.
